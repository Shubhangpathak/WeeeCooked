# Validated DSA Learning Sources — Working Notes

## Learner fit

The plan is calibrated for an MCA second-year student with basic coding fluency and familiarity with a few common algorithms. The intended outcome is durable problem-solving ability rather than passive course completion. The curriculum will therefore combine concise concept instruction, implementation, progressively sequenced problems, and spaced review.

## Sources reviewed

| Source | Evidence from source | Planning use |
| --- | --- | --- |
| [MIT 6.006 Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) | The course describes an introduction to mathematical modeling, common algorithms, paradigms, data structures, performance measures, and analysis; it provides videos, notes, practice problems, assignments, and solutions. | Use as the rigorous second-pass explanation for complexity, trees, sorting, hashing, graphs, and dynamic programming—not as the first exposure for every topic. |
| [MIT 6.042J Mathematics for Computer Science](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/) | The course is an interactive discrete-mathematics introduction for CS/engineering. Its visible scope includes definitions, proofs, sets, functions, relations, graphs, state machines, modular arithmetic; materials include notes, videos, textbook, and problem sets. | Use selected micro-lessons immediately before the DSA topics that need their mathematical language. Avoid treating it as a separate multi-month prerequisite. |
| [CSES Problem Set](https://cses.fi/problemset/) | The problem set visibly separates introductory problems, sorting/searching, dynamic programming, graph algorithms, range queries, tree algorithms, and mathematics. | Use only its approachable introductory, sorting/searching, basic DP, and graph tasks after foundational pattern practice. Do not begin here with advanced sections. |
| [NeetCode Roadmap](https://neetcode.io/roadmap) | Search discovery describes the roadmap as a recommended topic order that opens lists of problems. The page was dynamically unavailable in the research browser, so no claim is made about free access to every linked explanation. | Use the public roadmap only as an optional ordered problem map. Link to the source and label it “check availability”; do not make it the roadmap’s required primary source. |
| [William Fiset — Data Structures Easy to Advanced](https://www.youtube.com/watch?v=RBSGKlAvoiM) | Search discovery identifies this as a free full tutorial by William Fiset covering common data structures. Direct video access was rate-limited by YouTube in the research browser, but the public video URL remains usable as a free video recommendation. | Recommend as an optional visual first-pass companion for data structures; pair with implementation and problem work, not passive viewing. |
| [Striver’s A2Z DSA Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z) | The official page says it is free and structured, reports 474 total problems, and visibly orders 18 topic groups from basics and sorting through arrays, binary search, recursion, stacks/queues, trees, graphs, DP, and tries. | Use as the roadmap’s primary long-horizon question bank, but cap the weekly slice rather than attempting all 474 tasks. |
| [HackerRank Data Structures](https://www.hackerrank.com/domains/data-structures) | The page exposes easy starter challenges for arrays and linked lists and filters across arrays, lists, trees, stacks, queues, heaps, disjoint sets, tries, and levels. | Use for the first implementation repetition in arrays, linked lists, stacks, and queues, where low-friction easy problems build syntax and debugging confidence. |
| [VisuAlgo](https://visualgo.net/en) | The site explicitly presents animated visualizations and exposes modules for arrays, sorting, linked lists, heaps, hash tables, BSTs, graph structures, union-find, recursion/DP, graph traversal, MST, and shortest paths. | Use for a 10–15 minute trace before writing an unfamiliar algorithm. It is a mental-model tool, not a substitute for coding practice. |

## Initial resource-selection rule

One **primary explanation** and one **primary practice source** will be assigned to each stage. Extra playlists will be optional, preventing resource overload. All selected resources must be open to view/use without a required paid subscription; LinkedIn Learning is not a default recommendation because most full courses require an active membership.
